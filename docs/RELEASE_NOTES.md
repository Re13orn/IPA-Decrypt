# IPA 解密 1.0.4

**macOS 1.0.4 · iOS 1.0.1 — 操作体验更新**

- 应用列表可直接下载最新版；历史版本及免费授权保留在详情页和 Mac 更多菜单。
- 处理记录支持关键词搜索，以及全部、进行中、待处理、已完成四种筛选。
- Mac 根据记录状态突出重试、解密或导出操作，其余操作集中到菜单；缺少凭据时提供管理入口。
- 凭据详情默认展示常用操作，来源和许可证校验信息可按需展开。
- TestFlight 提供明确的登录、加载和空列表状态；iPhone 搜索栏、登录提示及应用信息排版更紧凑。

Mac 下载 `IPA-Decrypt-macOS-1.0.4-arm64.dmg`，要求 Apple Silicon / macOS 15+。采用 ad-hoc 签名，未公证。

iPhone 下载 `IPA-Decrypt-iOS-1.0.1-unsigned.ipa`，要求 iOS 16+；安装前需使用适用于目标设备的有效签名。

附件含源码及 SHA256SUMS。
