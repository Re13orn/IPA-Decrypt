# IPA 解密 1.1.0

macOS **1.1.0 (11)** · iOS **1.0.4 (5)**

## macOS

- 新增持久化任务队列，统一管理下载、导入和解密，支持暂停、重启恢复及取消待执行任务。
- 下载前确认 App Store / TestFlight 账户和处理方式；任务绑定所选账户，切换账户后等待匹配账户继续。
- 获取或导入凭据后返回原应用和历史版本；解密失败可复用原包重试。
- 下载期间可继续搜索；改进搜索反馈、账户入口、键盘导航及文件导出交互。
- 修复异步结果覆盖、导入排队和弹窗冲突等界面问题。

## macOS 与 iOS

- 新增六格验证码输入，支持整码粘贴、系统自动填充及退格修改；Mac 支持回车提交。
- 改进验证码重发状态和输入提示。

## 下载

- **Mac**：`IPA-Decrypt-macOS-1.1.0-arm64.dmg`，Apple Silicon / macOS 15+。
- **iPhone**：`IPA-Decrypt-iOS-1.0.4-unsigned.ipa`，iOS 16+，安装前需有效签名。
- 源码：`IPA-Decrypt-1.1.0-source.zip`；文件校验值：`SHA256SUMS`。

Mac 安装包采用 ad-hoc 签名，未公证。队列暂停在当前步骤完成后生效，取消待执行项不会删除已保存文件。iOS 不包含 Mac 专属任务队列。
