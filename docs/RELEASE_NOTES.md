# IPA 解密 1.0.6

**macOS 1.0.6 · iOS 1.0.3 — 凭据获取与使用体验更新**

- 凭据页可选择本机提取、越狱设备提取或导入已有文件，并直接进入 IPA 处理记录。
- 提取页按操作步骤组织，可选的指定 IPA 来源设置默认收起；确认的凭据自动保存。
- iPhone 明确支持的凭据格式，已有凭据时收起导入表单，保存后提供下一步操作。
- Mac 优先尝试同标签凭据，再尝试其他已保存的 16 字节凭据；按内容去重，最终以许可证校验为准。

Mac 下载 `IPA-Decrypt-macOS-1.0.6-arm64.dmg`，要求 Apple Silicon / macOS 15+。采用 ad-hoc 签名，未公证。

iPhone 下载 `IPA-Decrypt-iOS-1.0.3-unsigned.ipa`，要求 iOS 16+；安装前需使用适用于目标设备的有效签名。

附件含源码及 SHA256SUMS。使用步骤见仓库[凭据指南](https://github.com/Re13orn/IPA-Decrypt/blob/main/docs/CREDENTIALS.md)。
