# IPA 解密 1.0.5

**macOS 1.0.5 · iOS 1.0.2 — 多账户体验更新**

- App Store 与 TestFlight 页面分别显示当前下载账户，直接切换已保存账户。
- 账户选择与重新验证分开，登录表单按需展开；切换服务清除密码和验证码输入。
- 两种服务独立选择账户，App Store 自动搜索地区跟随其自身账户；同地区切换保留搜索结果。
- TestFlight 切换账户后重新读取列表；读取失败提供页面内刷新、切换及重新验证入口。
- 移除账户前明确提示影响范围，保留另一服务会话、已下载文件和 FairPlay 凭据。

Mac 下载 `IPA-Decrypt-macOS-1.0.5-arm64.dmg`，要求 Apple Silicon / macOS 15+。采用 ad-hoc 签名，未公证。

iPhone 下载 `IPA-Decrypt-iOS-1.0.2-unsigned.ipa`，要求 iOS 16+；安装前需使用适用于目标设备的有效签名。

附件含源码及 SHA256SUMS。
