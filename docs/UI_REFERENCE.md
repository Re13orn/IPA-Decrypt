# 界面设计参考

应用的信息组织参考 [mengangs/ipadn](https://github.com/mengangs/ipadn) 的搜索、应用详情与历史版本流程。参考版本为提交 `1a74050ac45455707ec3cadd93d310e8df3e427d`。

## 实现

Swift 视图、目录解析、下载入口及页面路由采用独立实现，并复用本项目的账户、认证与凭据处理流程。界面使用系统字体、系统强调色及原生明暗外观；iOS 采用导航详情，Mac 采用独立详情面板。

## 数据来源

应用详情来自 Apple 公开目录接口，按查询地区展示图标、开发者、版本、价格、评分、大小、兼容性、截图及更新说明。缺失字段按实际返回情况处理。

历史版本通过已登录的商店协议获取，展示服务器返回的版本信息。比价、已购目录同步、原生安装及完整多语言支持不属于当前功能范围。
