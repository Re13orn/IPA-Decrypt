# 凭据使用指南

## 选择获取方式

**这台 Mac 已安装商店中的 iPhone / iPad App**：在“FairPlay 凭据”选择“获取凭据 → 从这台 Mac 提取模型”。选择已安装应用，点击“提取并验证模型”，按 macOS 提示完成管理员授权。保存后可查看模型，或进入处理记录选择 IPA 解密。本机模型仅供 Mac 版使用。默认扫描 `/Applications`、`~/Applications` 及其子文件夹，仅列出检测到 iOS FairPlay 许可证的应用；其他位置可点“选择其他应用”。列表数量不代表凭据数量，是否可用须以提取验证结果为准。

**有越狱 iPhone / iPad**：在“越狱设备提取”选择 USB 或网络连接，填写 SSH 信息并测试连接，再点“全部提取并去重”。USB 仍需要设备 SSH 服务。确认的结果自动保存，相同内容合并；未完成项可重试。只有需要匹配指定 IPA 来源时，才展开可选的来源设置。

**已有文件或文本**：导入 credential.bin，或粘贴其 32 位十六进制表示。Mac 还支持导入本机模型文件；iPhone 支持 16 字节凭据，不接受本机模型文件。

## 用于 IPA

凭据保存后，解密会自动尝试候选并按许可证校验。账户标签会影响候选优先级，不会排除其他已保存的 16 字节凭据；相同内容仅尝试一次。

已有原始 IPA：从凭据页进入“选择 IPA 解密”，在处理记录中继续。新下载或导入的 IPA：保存完整原包后自动尝试解密。

## 没有匹配时

保留原始 IPA，导入其他凭据，或从与该 IPA 匹配的商店注册状态重新获取模型。修改账户标签不会改变凭据内容，也不会使其通过许可证校验。

本机模型的验证结果针对所选验证应用；其他 IPA 仍须单独校验。模型提取成功不代表所有应用或下载来源都适用。
