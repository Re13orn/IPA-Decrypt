# 更新记录

## macOS 1.1.0 / iOS 1.0.4

- Mac 新增持久化处理队列、账户固定、暂停与恢复、待执行项取消，以及保留原包的失败重试。
- 下载准备显示账户和处理方式，获取凭据后可返回原应用与所选版本。
- 优化 Mac 搜索、账户工具栏、键盘导航、导出和异步界面状态。
- 双端采用六格验证码输入，支持粘贴、系统自动填充、退格修改；Mac 支持回车提交。
- 修复弹窗冲突和异步结果覆盖问题。

## macOS 1.0.9 / iOS 1.0.3

- App Store 设备证明引擎随包分发，首次使用不再依赖外网下载 Unicorn 运行库。
- 校验固定版本归档及动态库 SHA-256，从安装包恢复缺失或损坏的缓存。
- 增加空缓存、禁止网络的 ARM64 引擎执行检查，以及缺失／损坏组件拦截测试。
- 细分运行库缺失、校验失败和缓存写入错误；修正 Mac 错误提示中的越狱设备措辞。
- iOS 未修改。

## macOS 1.0.8 / iOS 1.0.3

- 修复 TestFlight 空列表及错误状态下账户栏位置异常。
- 账户切换菜单显示当前账户，账户窗口跟随入口选择正确服务。
- 区分 TestFlight 会话拒绝、网络和返回格式错误，仅显示脱敏诊断；会话拒绝时提供重新验证入口。
- iOS 安装包未修改。

## macOS 1.0.7 / iOS 1.0.3

- 修复本机凭据提取遗漏应用目录子文件夹中的应用。
- 扫描跳过隐藏目录和 App 包内部，按实际路径去重。
- 应用列表显示检测数量，明确仅展示带 iOS FairPlay 许可证的应用。
- iOS 安装包沿用 1.0.3，未修改。

## macOS 1.0.6 / iOS 1.0.3

- 凭据库增加获取方式和选择 IPA 解密入口，本机提取成功后可查看模型并继续使用。
- 越狱设备提取按连接、测试、提取保存分组；可选来源设置默认收起。
- iPhone 增加格式与获取方式提示，已有凭据时收起导入表单，保存后提供下一步操作。
- Mac 16 字节候选改为按标签优先并尝试其他归属，按内容去重；实际仍须通过许可证校验。
- 增加跨标签候选、模型隔离及错误候选后的合成解密检查。

## macOS 1.0.5 / iOS 1.0.2

- App Store 与 TestFlight 页面显示各自的下载账户，支持直接切换已保存会话。
- 账户切换与重新验证分开；登录表单按需展示，切换服务清除密码和验证码输入。
- App Store 自动搜索地区只跟随 App Store 账户；同地区切换保留搜索结果。
- TestFlight 切换账户后重新读取列表；读取失败在页面内提供刷新和账户管理入口。
- 移除账户增加确认，明确只影响当前服务；会话恢复设置独立于登录表单。

## macOS 1.0.4 / iOS 1.0.1

- 应用列表支持直接下载最新版，历史版本等选项保留在详情页及 Mac 更多菜单。
- 两端处理记录增加关键词搜索与全部、进行中、待处理、已完成筛选。
- Mac 按记录状态突出下载、解密或导出操作，次要操作集中到菜单。
- Mac 缺少凭据时显示说明和管理入口；凭据详情按需展开来源及校验信息。
- Mac TestFlight 增加登录、读取中及空列表操作入口；iPhone 搜索栏和登录提示更紧凑。
- 应用列表元数据改为连续文本，避免窄屏下版本、大小和评分逐字换行。

## 1.0.3

- 修复 rootless 越狱环境中固定调用 `/bin/sh` 导致的提权失败，兼容 bootstrap shell 路径。
- 越狱设备提取新增自动、sudo、su 提权选择，支持单独填写 root 密码。
- 连接检测、许可证扫描及后台观察/触发进程统一使用已验证的提权方式。
- su 认证使用远程终端，二进制上传下载使用独立 SSH 通道，避免终端换行转换破坏数据。
- 增加 su 认证、提权失败、后台状态流及二进制传输回归检查。

## 1.0.2

- Mac 新增本机 FairPlay 模型提取、系统管理员授权及完整解密验证。
- 凭据管理支持本机模型的格式识别、归属标签、导入、导出与删除。
- 解密按实际许可证校验本机模型，保留原有 16 字节凭据路径。
- 本机模型与越狱设备凭据比对隔离；增加数据迁移、参数转义及服务流程验证。
- iOS 保持 1.0.0，本次无需更新。

## 1.0.1

- Mac 最低系统要求调整为 macOS 15，重新构建主程序、认证库、下载及 USB 组件。
- 增加安装包最低系统检查回归测试和 macOS 15 启动验证流程。
- iOS 保持 1.0.0，本次无需更新。

## 1.0.0

- iOS 与 macOS 统一版本号，构建号重置为 `1`。
- 确立统一的版本维护起点。
- 提供应用搜索、App Store / TestFlight 下载、凭据管理、IPA 解密与分享。
- Mac 提供越狱设备 USB / SSH 凭据提取。
- 保留现有应用标识与数据格式。

发行附件、平台要求及验证范围见 [发布说明](RELEASE_NOTES.md)。
