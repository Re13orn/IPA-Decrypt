# 更新记录

## 1.0.2

- Mac 新增本机 FairPlay 模型提取、系统管理员授权及完整解密验证。
- 凭据管理支持本机模型的格式识别、归属标签、导入、导出与删除。
- 解密按实际许可证校验本机模型，保留原有 16 字节凭据路径。
- 本机模型与越狱设备凭据比对隔离；增加数据迁移、参数转义及服务流程验证。
- iOS 保持 1.0.0，本次无需更新。

## 1.0.1

- Mac 最低系统要求调整为 macOS 15，重新构建主程序、认证库、下载及 USB 组件。
- 增加安装包最低系统检查回归测试和 macOS 15 启动验证流程。
- iOS 保持 1.0.0，本次无需更新。

## 1.0.0

- iOS 与 macOS 统一版本号，构建号重置为 `1`。
- 确立统一的版本维护起点。
- 提供应用搜索、App Store / TestFlight 下载、凭据管理、IPA 解密与分享。
- Mac 提供越狱设备 USB / SSH 凭据提取。
- 保留现有应用标识与数据格式。

发行附件、平台要求及验证范围见 [发布说明](RELEASE_NOTES.md)。
