# 更新记录

## 1.0.1

- Mac 最低系统要求调整为 macOS 15，重新构建主程序、认证库、下载及 USB 组件。
- 增加安装包最低系统检查回归测试和 macOS 15 启动验证流程。
- iOS 保持 1.0.0，本次无需更新。

## 1.0.0

- iOS 与 macOS 统一版本号，构建号重置为 `1`。
- 确立统一的版本维护起点。
- 提供应用搜索、App Store / TestFlight 下载、凭据管理、IPA 解密与分享。
- Mac 提供越狱设备 USB / SSH 凭据提取。
- 保留现有应用标识与数据格式。

发行附件、平台要求及验证范围见 [发布说明](RELEASE_NOTES.md)。
