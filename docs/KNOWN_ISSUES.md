# 兼容性与已知问题

## 平台支持

| 平台 | 支持范围 | 验证情况 |
| --- | --- | --- |
| macOS | Apple Silicon · macOS 15+ | 已完成安装包、依赖及隔离组件检查 |
| iOS | iOS 16+ | 已完成当前版本真机包编译与资源检查，设备完整流程待验收 |

实体新设备的完整登录、下载、解密与分享流程仍待验收，详见 [兼容性记录](PORTABILITY.md)。

## macOS 15 安装

macOS 15 用户请安装 Mac 版 1.0.1 或更高版本；Mac 1.0.0 要求 macOS 26，无法在 macOS 15 上启动。1.0.1 同时重新构建了 USB 辅助组件，不应通过修改旧 App 的 Info.plist 绕过系统要求。

## 本机模型

本机模型按商店注册状态和许可证匹配，Apple ID 管理标签不能代替实际校验。通过 App 内其他登录会话获取的 IPA 可能不匹配；此时可导入对应的 16 字节凭据。系统版本可启动 App，也不代表所有 FairPlay 注册格式均可恢复。未知格式、错误模型或不匹配的许可证会拒绝处理。

## 账户与服务

TestFlight 使用非公开客户端协议，会话建立及下载流程可能受到 Apple 服务调整影响。出现错误时，请提供诊断阶段码，以区分账户验证、会话交换和下载阶段。

App Store 会话恢复需要已保存的有效密码。服务器要求验证码或其他账户验证时，应用将转入交互式验证。

## 文件导入

iOS 18.1.1 的个别设备曾出现系统文件选择器及“文件”服务白屏或卡住。可使用十六进制方式导入凭据；系统文件服务异常时，重启设备后重试。触发条件仍在排查。

## 下载与任务恢复

任务重试支持重新发起处理。按字节断点续传、后台执行和进程中断后的恢复能力仍需进一步完善，各平台行为可能存在差异。

## macOS 安装

当前发行包采用 ad-hoc 签名，未公证。首次打开方式见 [安装指南](INSTALLATION.md)。曾出现 Finder 启动注册异常导致的打开失败，相关根因仍待确认。

## 本地数据与构建

iOS 数据位于应用沙盒；Mac 数据位于 Application Support，并设置目录及文件权限。已保存密码采用本机文件存储，相关保护范围见 [数据与隐私](PRIVACY.md)。

源码构建需另行准备生成库及外部运行资源，具体版本与内容摘要见 [依赖清单](DEPENDENCIES.md)。
