# 版本策略

iOS 与 macOS 使用统一的版本系列。平台专属修复可独立递增修订版本：当前 macOS 为 `1.0.6 (7)`，iOS 为 `1.0.3 (4)`。本次发布标签为 `v1.0.6`，包含 Mac 与 iOS 安装包。

## 版本规则

版本号采用 `主版本.次版本.修订版本`：

- 修订版本：缺陷修复与兼容性调整。
- 次版本：向后兼容的功能更新。
- 主版本：涉及不兼容变化的更新。

构建号随发布递增。仓库仅提供当前发布系列的源码文档与发行附件。

## 安装与数据

应用标识与数据格式保持兼容。签名 Team、Bundle ID 或访问组变化可能影响覆盖安装与数据访问，替换安装前请导出需要保留的文件。
