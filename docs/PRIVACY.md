# 数据与隐私

## 存储位置

| 平台 | 默认位置 |
| --- | --- |
| iOS | 应用沙盒 |
| macOS | `~/Library/Application Support/IPADecryptMac` |

本机数据可能包含账户会话、用户选择保存的密码、FairPlay 凭据、任务记录、下载文件与设备提取资料。导出文件保存至用户选择的位置。

## 密码与凭据

保存密码为可选功能，会话自动恢复仅使用对应账户已保存的密码。SSH 密码仅用于当前操作，不写入磁盘。凭据查看与复制由用户主动触发。

私密文件采用原子写入及平台文件保护选项。Mac 数据目录权限为 `0700`，私密文件权限为 `0600`。密码文件采用本机 JSON 存储，未实施应用层加密；具有相同用户权限的其他程序仍可能访问相关文件。

账户标签用于整理凭据记录，实际匹配结果由许可证校验确定。

## 局域网分享

开启网页分享后，持有分享地址且网络可达的访问者可以下载选中的 IPA。分享完成后应停止服务。当前分享功能的访问控制与链接时效仍待完善。

## 问题反馈

请提供应用版本、系统版本、诊断阶段码及脱敏复现步骤。密码、验证码、Cookie、会话令牌、真实凭据、签名材料及设备转储应保留在受控环境中。
