# iOS 应用

版本 **1.0.0**，构建号 **1**，最低 iOS 16。

工程入口：`IPALab.xcodeproj`，Scheme：`IPALab`，应用名称：IPA 解密。

从仓库根目录运行 `bash scripts/build.sh ios`。真机安装需要适用于目标设备的有效签名。
