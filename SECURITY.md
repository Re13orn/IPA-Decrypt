# Security reports / 安全报告

## Supported versions / 版本支持

Fixes target the latest published version of each platform. Older versions are not maintained independently. Current downloads are listed in the [README](README.md#download).

修复面向两端各自的最新发布版本，旧版本不单独维护。当前安装包见[中文 README](README.zh-CN.md#下载)。

## Private reporting / 非公开报告

Report sensitive issues privately to the repository maintainer. A dedicated security contact address has not been published; agree on a private channel before sending detailed evidence. Until then, limit initial contact to an impact summary and redacted steps.

安全问题请通过非公开渠道联系仓库维护者。专用安全联系地址尚未公布；请先确认私有沟通渠道，再提供详细证据。初次沟通仅提供影响概述和脱敏复现步骤。

Include the affected app/OS versions, trigger, impact, minimal reproduction, and any mitigation. Do not post passwords, verification codes, cookies, session tokens, real credentials, signing material, or device dumps in public issues, pull requests, or logs.

报告应说明版本、触发条件、实际影响、最小复现及可行缓解措施。请勿在公开 Issue、PR 或日志中提交密码、验证码、Cookie、会话令牌、真实凭据、签名材料或设备转储。

Configured source scans cover known patterns and synthetic fixture hashes; they are not a complete security assessment.

源码扫描仅覆盖已配置模式及合成测试夹具摘要，不代表完整安全评估。
